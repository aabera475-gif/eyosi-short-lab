How to use it

    
እንዴት እንደሚሰራ፣ በ4 ቀላል ደረጃ

    
    
      
  1. Turn on file creation once
    In Claude, open Settings, then Capabilities. Turn on code and file creation, and allow internet access while making files. Claude needs this to download free fonts and build the video.
    2. 
      
  2. Copy your prompt
    Pick a style and topic above, then press Copy my prompt.
    3. 
      
  3. Paste in a new chat
    Open claude.ai, start a new chat, paste and send. The free plan works for these 2D styles.
    4. 
      
  4. Say yes to the plan
    Claude first shows the script and shot list. Fix anything you want, say "Build it", and wait about 10 minutes for your MP4.
    5. 
    

    
Free plan tip: if Claude says you reached your limit, wait a few hours and type "continue" in the same chat.

  


  

    

      

        
Make your own style

        
የወደድከውን ስታይል ወደ ራስህ ስታይል ቀይር

        
    
          
  1. Find a Short whose look you like and take 1 to 3 screenshots.
    2. 
          
  2. Pick the closest starting style, type a topic, and copy the prompt.
    3. 
          
  3. Paste it in a new Claude chat, attach the screenshots and send.
    4. 
          
  4. Claude shows you one test picture first. Say OK, and it builds the Short.
    5. 
        

      

      

        
        
        
        
        
Claude makes a new, original character and look inspired by your screenshots. It will not copy another creator's character, logo or name.
